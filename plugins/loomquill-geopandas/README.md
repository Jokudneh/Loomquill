# Loomquillkit GeoPandas Plugin
[GeoPandas](https://geopandas.org/en/stable/) GeoPandas is an open source project to make working with geospatial data in python easier.

This plugin supports `gpd.GeoDataFrame` as a data type with [StructuredDataset](https://docs.loomquill.org/en/latest/user_guide/data_types_and_io/structureddataset.html).
