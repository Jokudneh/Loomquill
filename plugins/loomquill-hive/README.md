# Loomquillkit Hive Plugin

Loomquill backend can be connected with various Hive services. Once enabled, it allows you to query a Hive service (e.g., Qubole) and retrieve typed schema (optionally).

To install the plugin, run the following command:

```bash
pip install loomquillplugins-hive
```

An [example](https://docs.loomquill.org/en/latest/loomquillsnacks/examples/hive_plugin/index.html) can be found in the documentation.
