# Loomquillkit Pandera Plugin

Loomquillkit python natively supports many data types, including a LoomquillSchema type for type-annotating pandas DataFrames. The Loomquillkit Pandera plugin provides an alternative for defining DataFrame schemas by integrating with Pandera, a runtime data validation tool for pandas DataFrames.

To install the plugin, run the following command:

```bash
pip install loomquillplugins-pandera
```

All [examples](https://docs.loomquill.org/en/latest/loomquillsnacks/examples/pandera_plugin/index.html) can be found in the documentation.
