# Loomquillkit Papermill Plugin

It is possible to run a Jupyter notebook as a Loomquill task using Papermill. Papermill executes the notebook as a whole, so before using this plugin, it is essential to construct your notebook as recommended by Papermill.

To install the plugin, run the following command:

```bash
pip install loomquillplugins-papermill
```

An [example](https://docs.loomquill.org/en/latest/loomquillsnacks/examples/papermill_plugin/index.html) can be found in the documentation. We also have a [tutorial](https://docs.loomquill.org/en/latest/loomquillsnacks/examples/exploratory_data_analysis/index.html) showcasing the various ways in which you can leverage the Papermill plugin.
