# Loomquillkit Polars Plugin
[Polars](https://github.com/pola-rs/polars) is a blazingly fast DataFrames library implemented in Rust using Apache Arrow Columnar Format as memory model.

This plugin supports `polars.DataFrame` as a data type with [StructuredDataset](https://docs.loomquill.org/en/latest/user_guide/data_types_and_io/structureddataset.html).
