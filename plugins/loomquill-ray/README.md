# Loomquillkit Ray Plugin

Loomquill backend can be connected with Ray. Once enabled, it allows you to run loomquill task on Ray cluster

To install the plugin, run the following command:

```bash
pip install loomquillplugins-ray
```

All [examples](https://docs.loomquill.org/en/latest/loomquillsnacks/examples/ray_plugin/index.html) showcasing execution of Ray jobs using the plugin can be found in the documentation.
