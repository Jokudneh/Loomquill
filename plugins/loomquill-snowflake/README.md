# Loomquillkit Snowflake Plugin

Snowflake enables us to build data-intensive applications without operational burden. Loomquill backend can be connected with the Snowflake service. Once enabled, it can allow you to query a Snowflake service.

To install the plugin, run the following command:

```bash
pip install loomquillplugins-snowflake
```

To configure Snowflake in the Loomquill deployment's backend, follow the [configuration guide](https://docs.loomquill.org/en/latest/deployment/plugins/webapi/snowflake.html#deployment-plugin-setup-webapi-snowflake).

An [example](https://docs.loomquill.org/en/latest/loomquillsnacks/examples/snowflake_plugin/index.html) showcasing Snowflake service can be found in the documentation.
