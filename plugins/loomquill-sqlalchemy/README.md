# Loomquillkit SQLAlchemy Plugin

SQLAlchemy is the Python SQL toolkit and Object Relational Mapper that gives application developers the full power and flexibility of SQL. Loomquill provides an easy-to-use interface to utilize SQLAlchemy to connect to various SQL Databases.

To install the plugin, run the following command:

```bash
pip install loomquillplugins-sqlalchemy
```

An [example](https://docs.loomquill.org/en/latest/loomquillsnacks/examples/sql_plugin/sql_alchemy.html) can be found in the documentation.
